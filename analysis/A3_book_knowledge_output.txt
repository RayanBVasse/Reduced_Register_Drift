Does Cond_A3 show book knowledge it was never given?

The A3 system prompt supplies title and author only. Any book-internal
entity in an A3 reply therefore comes from pretraining, not from context.

Implication: A3 is not a 'no book knowledge' condition. It is a 'no book
content in the prompt' condition applied to a model that already knows these
works. The A3 vs B contrast therefore tests whether an explicit interpretive
profile adds anything for texts the model has already absorbed -- not whether
book-specific governance matters in general.
